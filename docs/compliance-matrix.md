# ZATCA compliance matrix

Evidence through the M7 API work as of 2026-11-03. **Implemented** means the local feature exists and may have known defects. **SDK verified** requires a recorded official SDK version, fixture and result. **Sandbox verified** requires a recorded Sandbox specification and successful workflow evidence. The current evidence consists of local tests, packed consumer and browser checks, official document review and representative live Sandbox workflows. Official SDK validation remains pending.

The [official SDK toolkit][sdk] is the validation source for supported invoice profiles. Record the SDK version, fixture provenance, command and actual outcome before upgrading a row. Local QR parsing, visual scan, official SDK verification and successful Sandbox submission are distinct checks. The [M0 audit](m0-baseline.md) records the local results.
