استقبل بيانات الفاتورة من التطبيق

Receive the invoice object from your application

بعد ما الـAPI يقرأ جسم الطلب، بيانات الفاتورة بتكون object في req.body. المثال التالي يوضح شكل البيانات اللي هتمرّرها للدالة.

After your API parses the request body, the invoice is an object in req.body. This sample shows the data you pass to the function.

const invoice = req.body;

02
مرّر الـobject واستلم XML
Pass the object and get XML back

    
generateXml() تأخذ object واحد وترجع string. chainLink يأتي من خادمك، وفيه عدّاد الفاتورة وهاش الفاتورة السابقة لنفس الجهاز.

    
generateXml() takes one object and returns a string. Your server supplies chainLink with the invoice counter and previous invoice hash for the device.

    
import { generateXml } from '../../src/server/invoicing.js';

const draftXml = generateXml({ ...invoice, ...chainLink });

03
احسب الهاش وأرسل الـXML نفسه
Hash the XML and send that same string

    
للمبسطة، مرّر draftXml لمزوّد التوقيع عشان يرجع XML موقّع وفيه QR المرحلة الثانية. احسب الهاش من النص اللي رجع، ثم ابعت النص والهاش معًا إلى reportXml().

    
For a simplified invoice, pass draftXml to your signer. It returns signed XML with the Phase 2 QR. Hash the returned string and pass that string and its hash to reportXml().

    
للقياسية، احسب هاش draftXml بعد تجهيز المستند، ومرّر النص نفسه والهاش إلى clearXml(). عند القبول، زاتكا ترجع XML التخليص.

    
For a standard invoice, hash draftXml after preparing it and pass the same string and its hash to clearXml(). On acceptance, ZATCA returns the cleared XML.

    

    
    
اقرأ result.status. المثال يعرض نتيجة قبول. التفاصيل في diagnostics وحالة HTTP في metadata.httpStatus.

    
Read result.status. This is an example of an accepted result. See diagnostics for validation details and metadata.httpStatus for the HTTP status.

    

    
الـXML الراجع كنص في الذاكرة هو Buffer.from(result.clearedInvoiceBase64, 'base64').toString('utf8') بعد التأكد من أن الحالة cleared.

    
After checking for cleared, get the returned XML string with Buffer.from(result.clearedInvoiceBase64, 'base64').toString('utf8').

  


  

    
إعداد الإرسال مرة واحدة على الخادم
Configure submission once on your server

    
createInvoicing() تهيّئ عميل الإرسال. خذ شهادة الإصدار csid من تهيئة جهازك في زاتكا. فيها requestId وbinarySecurityToken وsecret، ومع شهادة اختبار تكون environment: 'sandbox' وkind: 'production'. xmllintPath مسار أداة الهاش على الخادم، وsignSimplified دالة التوقيع التي يوفّرها تطبيقك.

    
createInvoicing() sets up the submission client. Use the issuance csid obtained when onboarding your device. It contains requestId, binarySecurityToken and secret. A Sandbox issuance CSID has environment: 'sandbox' and kind: 'production'. xmllintPath points to the server canonicalizer, and your application provides signSimplified.

    
import { createInvoicing } from '../../src/server/invoicing.js';

const invoicing = createInvoicing({ environment: 'sandbox', csid });

    
لو الـXML والهاش جاهزين بالفعل، ابدأ من reportXml({ xml, invoiceHash }) للمبسطة الموقّعة أو clearXml({ xml, invoiceHash }) للقياسية.

    
If you already have the XML and hash, start with reportXml({ xml, invoiceHash }) for a signed simplified invoice or clearXml({ xml, invoiceHash }) for a standard invoice.

    
وظائف الفواتير دي موجودة في كود Node داخل المستودع. التوقيع الفعلي للمبسطة يأتي من مزوّد خارجي. حزمة npm الحالية تعرض وظائف QR.

    
These invoice functions live in the repository's Node source. An external signer provides the simplified invoice signature. The current npm package exposes QR functions.

  

  

    
QR فقط — من بيانات الفاتورة لصورة في الصفحة

    
QR only — from invoice fields to an image on the page

    
المثال التالي لنسخة التطوير 2.0.0-dev.0 بعد تثبيت ملف الحزمة المحلي. تقدر تنفّذه في تطبيق متصفح. مرّر بيانات الفاتورة كـobject، وحطّ رابط الصورة الناتج في src للـ<img>.

    
Use the following browser example after installing the local 2.0.0-dev.0 tarball. Pass the invoice fields as an object, then assign the returned image URL to the <img> element's src.

    
<img id="invoice-qr" alt="Invoice QR" width="180" height="180">

    
import { encodeQrTlv, encodeBase64 } from 'zatca/qr';
import { qrToDataUrl } from 'zatca/qr/render';

const fields = {
  sellerName: 'شركة مدار التجريبية',
  vatNumber: '300000000000003',
  issuedAt: '2026-11-03T15:30:00+03:00',
  invoiceTotal: '230.00',
  vatTotal: '30.00',
};

const tlv = encodeQrTlv(fields);       // Uint8Array
const base64 = encodeBase64(tlv);      // string
const imageUrl = await qrToDataUrl(base64, { width: 320 });

document.querySelector('#invoice-qr').src = imageUrl;

    
    
لو محتاج Base64 فقط، استدعِ encodeQrBase64(fields) من zatca/qr مباشرة. لقراءة الحقول استخدم decodeQrBase64(base64)، وللفحص استخدم validateQrPayload(base64). في React أو Vue استخدم نفس imageUrl كقيمة src.

    
For Base64 alone, call encodeQrBase64(fields) from zatca/qr directly. Use decodeQrBase64(base64) to read the fields and validateQrPayload(base64) to validate the payload. In React or Vue, bind the same imageUrl to src.

      مثال npm المنشور حاليًا · zatca@1.0.2Current npm release · zatca@1.0.2
      
في الإصدار المنشور، ولّد البيانات والصورة على Node.js. لو هتعرض الصورة في موقعك، رجّع imageUrl للواجهة واستخدمها كقيمة src.

      
In the published release, generate the data and image on Node.js. To show it on your website, return imageUrl to the frontend and assign it to src.

      
npm install zatca@1.0.2 qrcode@1.5.4

      
const { GenerateQrCode } = require('zatca');

async function generateInvoiceQr() {
  const qr = new GenerateQrCode(
    'Example Store',
    '300000000000003',
    '2026-11-03T12:30:00.000Z',
    230,
    30,
  );

  return {
    tlv: await qr.getTLV(),        // Buffer
    base64: await qr.toBase64(),   // string
    imageUrl: await qr.render(),  // PNG data URL
  };
}
